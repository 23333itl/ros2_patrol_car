# 后期锯齿墙诊断与候选结果

同一份 1510 秒导航记录表明，激光用 Gazebo 真值投影时墙面 P95 误差约 0.018 m；锯齿主要来自累计平面位姿误差，不是激光噪声或栅格显示本身。原 `baseline` 回放最大位置/航向误差约 0.559 m / 15.4°，连续墙面平行方向散布约 25.2°。

`simulation_stable` 禁止无先验邻近扫描链并强化航向先验，关闭回环。对应回放把最大位置误差降到约 0.103 m、回访错位降到 0.092 m，未出现超过 0.10 m / 2° 的单次定位修正；连续墙面平行方向散布仍约 7.06°，没有达到最终 2° 验收，因此启动默认不自动切换。

局部回环搜索半径 0.35 m 的候选能把地图视觉显著拉直，但完整回放仍出现 2.24° 地图墙方向误差、3.19° 平行墙散布，并在图增大后产生计算拥塞。把扫描队列增到 5 可消除丢帧，但最大位置误差恶化到 0.219 m；把关键帧阈值增到 0.08 m / 0.05 rad 又恶化到 0.279 m。两者均不作为正式参数。

显式验证较安全的无回环候选：

```bash
ros2 launch maze_explorer explore_maze.launch.py \
  world:=/ros_ws_pool/maze_ws/maze_output/maze.world \
  slam_profile:=simulation_stable
```

为什么这样处理：对称迷宫中的回环或邻近链可能把相似墙段连错；继续放宽平移搜索、增大队列或减少关键帧，虽然能改变画面，却会恶化真值误差。保留顺序匹配和准确的 IMU 航向先验，可在不改变底盘、导航速度和碰撞余量的前提下减少最严重的后期扭曲。
